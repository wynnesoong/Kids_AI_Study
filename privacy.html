Privacy Policy

Effective date: 2026-11-16

What PersonalBrain accesses

With the owner's consent, PersonalBrain uses the Gmail API scope https://www.googleapis.com/auth/gmail.readonly to read messages and attachments in the owner's own Gmail account. It cannot send, delete, or change any email.

How the data is used

  • Data is processed only on the owner's own computer, to help the owner read and organize personal bills and statements.
  • Data is not sold, shared, or transferred to third parties, and is not used for advertising.
  • This app does not use Google user data to develop, improve, or train generalized AI or machine-learning models.
  • The owner may use an AI assistant on their own computer to read and summarize these emails on the owner's own behalf.

Storage and security

Authorization tokens are stored only on the owner's computer, in a folder readable only by the owner. Downloaded attachments are temporary copies readable only by the owner.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

Google API Services User Data Policy

PersonalBrain's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
